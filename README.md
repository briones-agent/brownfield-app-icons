# Brownfield App Icons

App icons/logos for the 85 open-source apps integrated as [Expo brownfield examples](https://github.com/expo/expo-brownfield-examples) (Android + iOS). Sourced from each app's own repository (app-icon asset catalogs / launcher mipmaps / store icons).

Icons live in [`icons/`](icons/). A combined [`contact-sheet.png`](contact-sheet.png) shows all of them at a glance.
